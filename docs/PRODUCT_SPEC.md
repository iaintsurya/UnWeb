# Product experience
- Evidence first: observed headers and markup are distinct from heuristic detections.
- Progressive disclosure: compact summary, raw evidence in a detail drawer.
- No fake activity: show actual request states and clear errors.
- Light forensic theme: off-white canvas, white panels, slate text, 1px borders, muted amber selected state.
- Sans-serif interface; monospaced URLs, headers and code.
- Error states for timeout, rejected private destination, missing scripts and missing source maps.
- Future improvements: virtualized tables, graph canvas, keyboard command palette, screenshot comparison.
